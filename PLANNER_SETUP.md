# June Planner — setup & how it works

A personal planning app built on the "big rocks" framework from the car conversation:
**big rocks → milestones (deadline, hours, priority, status) → scheduled into your time.**
It auto-saves every change to the cloud, so you can open it on any device and always see the latest.

- **App page:** https://inikaiyer.com/planner.html  (served by GitHub Pages)
- **Save/load API:** https://inikaiyer-portfolio.vercel.app/api/planner  (Vercel function — same place your chatbot lives)

## Files
- `planner.html` — the whole app (one file, no build step). Lives on GitHub Pages.
- `api/planner.js` — Vercel serverless function that loads/saves your data to a **private Vercel Blob**.
- `PLANNER_SETUP.md` — this file.

It already works offline: your data is cached in the browser (localStorage), so nothing is ever lost.
The two steps below turn on **cloud sync across devices**.

## One-time setup (≈5 min, in the Vercel dashboard)
Go to https://vercel.com → your **inikaiyer-portfolio** project.

**1. Create the storage (Vercel Blob)**
   - Top tabs → **Storage** → **Create Database** → choose **Blob** → name it `juneplanner` → Create.
   - When asked, **Connect** it to the `inikaiyer-portfolio` project (all environments).
   - This automatically adds `BLOB_READ_WRITE_TOKEN` to the project — you don't copy anything.
   - Your data stays **private**: the file is never publicly accessible — only this function (which holds the token) can read or write it.

**2. Set your private PIN**
   - **Settings** → **Environment Variables** → Add:
     - Key: `PLANNER_PIN`   Value: *(a code only you know, e.g. `2026`)*
   - Save.

**3. Redeploy so the new settings take effect**
   - **Deployments** → newest one → **⋯** → **Redeploy**.

Then open https://inikaiyer.com/planner.html, enter your PIN once (remembered on that device).
On your phone: open it in Safari/Chrome → **Share → Add to Home Screen** for an app icon.

> If you skip step 2 (the PIN), the planner still works but has **no lock** — anyone with the link could edit it.
> Until step 1 is done, the app runs in offline mode (saves only on the current device) and the status dot shows "Offline".

## How to use it
- **Today** — a 🟢/🟡/🔴 **trend chip** (on track / slipping / behind). If you're slipping, a **nudge banner**
  names which rocks and what's due, with an encouraging push. Each rock shows a colored dot, a progress bar,
  and **hours left**.
- **Rocks** — tap a rock to expand its milestones; tap the circle to cycle To-do → In progress → Done.
  Tap a milestone (or ✎) to set its **deadline, hours, priority, notes**. Move a deadline and the
  urgency/colors re-sort automatically — that's the dynamic re-planning.
- **Schedule** — pick a day in June; recurring classes/work are auto-filled.
  - **✨ Auto-plan my work** looks at your deadlines + estimated hours and lays a draft of work **sessions**
    into your free time (deadline-first, never on top of class/work). It shows the plan; you **Accept** or
    **Discard**. Re-run anytime — finished work is kept.
  - **🕐 Free time** sets the windows you're free (the only times Auto-plan will use).
  - Tap a session's circle as you finish it → your rock progress, "hours left", and R/Y/G status update
    automatically. Tap **＋ add** to block any other time.

### How red/yellow/green works
Green = keeping up. **Yellow** = you missed a planned session, or something's due in ≤2 days with lots left.
**Red** = a deadline passed unfinished, or work can't fit before its deadline. Do your sessions on time →
trend green; skip them → trend red.

## Notes
- Single shared document (meant for one editor — you). Multi-user can be added later.
- Recurring commitments (Tech Theater, Bellevue math, work shifts) and default free-time windows live in
  `planner.html`'s `seed()` function — edit there, or use the in-app **🕐 Free time** editor.
- The nudge's encouraging line is generated by `api/nudge.js` (reuses your existing `ANTHROPIC_API_KEY`);
  if unavailable, the app falls back to a built-in line.
- iOS app: planned for later. The app already installs to your Home Screen (Share → Add to Home Screen).
